# card-insight — 카드사용내역분석 에이전트

한 달치 카드 이용내역(xlsx/csv)을 **로컬에서만** 분석해서 평균 소비, 주 사용처, 과소비 Top3, 절약 제안을 담은 `.docx` 리포트 1건을 만듭니다.
Claude Code 같은 에이전트가 자연어 요청을 `main.py`로 넘겨 실행하는 구조이고, 이를 위한 하네스(CLAUDE.md + 스펙 5종)가 함께 들어 있습니다.

## 핵심 원칙

- **로컬 전용**: 외부 API와 LLM을 호출하지 않습니다. 카드사 API, 오픈뱅킹 같은 외부 데이터도 쓰지 않습니다.
- **PII 마스킹**: 카드번호, 전화번호, 이름은 파일을 읽는 즉시 가립니다.
- **외부 전송 금지**: 표준출력은 에이전트(LLM)가 읽기 때문에 외부 전송으로 봅니다. 그래서 표준출력에는 비율과 카테고리명만 내보내고, 금액과 가맹점명은 docx에만 담습니다.
- **단정 금지**: "OO 끊어!" 대신 "OO 카테고리 지출이 전월 대비 X% 증가. 검토 권장." 형식으로 씁니다. 단정 표현이 발견되면 리포트를 만들지 않습니다.
- **금융상품 추천 거부**: 대출, 카드, 금융상품은 추천하지 않습니다.
- **수치는 파이썬 계산 결과만** 씁니다.

## 구조

```
CLAUDE.md                      에이전트 지침 (라우팅, 절대규칙, 운영 한도)
specs/
  system_prompt.md             답변 형식, 종료코드별 응답
  architecture.md              흐름, 정제 규칙, 지표 정의, 키워드 규칙, 표준출력 규칙
  guardrails.md                마스킹, 외부 전송 금지, 단정 금지, 면책문구
  retry_policy.md              재시도 정책, 카드분석검증
  memory_policy.md             저장하는 것과 저장하지 않는 것
agents/card-insight/
  main.py                      진입점: 요청 해석 → 실행 → 표준출력, 종료코드
  csv_loader.py                파일 읽기, 헤더 탐지, 카드사 식별, 정제, 재시도
  merchant_normalizer.py       PII 마스킹, 가맹점명 정리, 익명화 토큰
  category_classifier.py       키워드 규칙 기반 카테고리 분류
  statistics_engine.py         지표, 전월 비교, 과소비 Top3, 월별 요약 메모리
  advisor.py                   거부 판정, 절약 제안, 단정 표현 검사, 검증
  report_writer.py             docx 리포트, 면책문구
  test_card_insight.py         테스트
memory/card/                   카드사 식별 기록, 월별 요약 (json은 git 제외)
output/card-report/            생성된 리포트 (git 제외)
```

## 사용법

필요 패키지: Python 3.10+, `openpyxl`, `python-docx`

```bash
pip install openpyxl python-docx
python agents/card-insight/main.py "4월 지출 정리해줘"
python agents/card-insight/main.py "4월대비 5월에 지출이 늘어난 곳은?"
python agents/card-insight/main.py "5월 카페 지출 정리해줘"     # 카페 강조 단락 추가
python agents/card-insight/main.py "디버그"                      # 파일별 처리 건수
```

- 입력: 기본값은 `../harness-book-samples/card-insight/*.xlsx|*.csv`이며, `--input 폴더`로 바꿀 수 있습니다.
- 출력: `output/card-report/{YYYYMMDD}_report.docx`이며, 날짜는 분석 월의 말일입니다.
- 카드사를 식별하지 못하면 컬럼명을 보여주고 종료합니다. 이때 `--issuer "카드사명"`을 붙여 다시 실행하면 그 시그니처를 기억합니다. 신한카드 형식은 내장되어 있습니다.

표준출력 예시:

```
결과파일: .../output/card-report/20260531_report.docx
분석 월: 2026-05
총 사용액: 전월 대비 40.1% 감소 (금액은 리포트 참조)
과소비 Top3 (전월 대비, 초과액 순): 여가(전월 대비 35.6% 증가)
절약제안: 여가•구독 카테고리 검토 권장, 할부 결제 점검 권장 (절감액(추정)은 리포트 참조)
※ 본 리포트는 ... (면책문구)
```

### 종료코드

| 코드 | 의미 |
|---|---|
| 0 | 성공 |
| 1 | 오류, 요청 거부(단정 표현·외부 전송·금융상품), 검증 실패 |
| 2 | 입력 없음 또는 요청한 월의 데이터 없음 (사용 가능한 월 목록 출력) |
| 3 | 카드사 식별 실패 → `--issuer`로 다시 실행 |
| 4 | 60초 한도 초과 |

## 분석 규칙 요약

- 취소·취소전표접수 거래는 원거래와 함께 제외합니다. 할부는 승인 시점에 전액 계상합니다.
- 전월과 커버 일수가 다를 수 있으므로 카테고리별 **일평균**으로 바꿔 비교합니다.
- **과소비 Top3**는 전월보다 늘어난 카테고리를 **초과액 순**으로 고릅니다(증가율 순이 아님). 3만원 미만이거나 총액의 3% 미만인 카테고리는 제외합니다.
- 전월 데이터가 없거나 7일 미만이면 비교하지 않고, 대신 금액 상위 3개 카테고리를 보여줍니다.
- 키워드 규칙에 맞지 않는 가맹점은 "기타"로 두고, 리포트의 "미분류 가맹점" 목록에 표시합니다.

자세한 내용은 [`specs/architecture.md`](specs/architecture.md)에 있습니다.

## 테스트

```bash
python agents/card-insight/test_card_insight.py
```

테스트는 임시 폴더만 쓰므로 실제 `memory/`와 `output/`은 건드리지 않습니다. 확인하는 항목은 마스킹, 분류, 요청 해석, 거부, 재시도, 종료코드 0~4, 검증 실패 차단, 메모리 저장 실패 처리입니다.

## 면책

이 프로젝트가 만드는 리포트는 입력된 카드 이용내역만으로 자동 생성한 참고 자료이며, 금융·세무·투자 자문이 아닙니다.
