# retry_policy.md — 재시도 정책

원칙: **일시적인 I/O 오류만** 재시도한다. 데이터·형식 오류는 재시도해도 결과가 같으므로 즉시 실패시킨다.

| 상황 | 예외 | 재시도 | 대기 | 최종 실패 시 |
|---|---|---|---|---|
| 입력 파일 읽기 (Excel에서 열려 잠김 등) | `PermissionError`, `OSError` | 최대 3회 | 0.5s → 1s → 2s | 해당 파일 건너뛰고 경고 출력 |
| 리포트 저장 (Word에서 열려 잠김 등) | `PermissionError` | 최대 3회 | 0.5s → 1s → 2s | 종료코드 1, "파일을 닫고 다시 실행" 안내 |
| 메모리 파일 쓰기 | `PermissionError`, `OSError` | 최대 3회 | 0.5s → 1s → 2s | 경고만 출력 (리포트는 이미 생성됨) |

## 재시도하지 않는 경우
- 헤더 행을 찾지 못함 → 해당 파일 건너뜀 (경고)
- 카드사 식별 실패 → 종료코드 3, 사용자 확인 필요
- 요청한 월의 데이터 없음 → 종료코드 2, 사용 가능한 월 목록 출력
- 단정 표현·PII 검사 실패 → 즉시 중단 (가드레일 위반)
- 카드분석검증 실패 → 즉시 중단, 실패 항목 출력 (아래 "카드분석검증" 참조)

## 시간 한도와의 관계
- 대기 시간을 포함한 모든 재시도는 요청당 60초 한도 안에서만 한다.
- 다음 대기가 한도를 넘기면 재시도하지 않고 바로 실패 처리한다.
- 구현: `csv_loader.with_retry(fn, exceptions, deadline)`

### 카드분석검증
리포트를 만들기 전에 아래 4가지를 검사한다. 판정 기준은 기존 스펙(architecture.md, guardrails.md)을 따른다.

| 검사 | 통과 조건 | 실패 시 |
|---|---|---|
| 가맹점 → 카테고리 분류 신뢰도 | 키워드 규칙에 맞으면 신뢰도 1.0, 맞지 않으면 0. 0.6 미만이면 "기타"로 둔다 | 재분류하지 않는다. 리포트에 "미분류 가맹점" 목록을 표시한다. 외부 LLM으로 재분류하지 않는다 (guardrails.md 3번) |
| 카테고리 합계 = 총 사용금액 | 오차 ±0.1% 이내 | 중단 (종료코드 1) |
| 과소비 Top3 선정 기준 명시 | 리포트에 "전월 대비, 초과액 순" 기준 문구가 있음 (architecture.md) | 중단 (종료코드 1) |
| 절약제안 정량근거 | 각 항목에 금액과 비율(전월 대비 X%)이 모두 있음. 단, 전월 비교가 불가능한 항목(전월 없음(신규) 카테고리, 전월 데이터 없음, 할부·구독 점검 제안)은 금액만 있어도 통과 | 중단 (종료코드 1) |

검증 실패는 재시도하지 않는다. 같은 입력으로 다시 계산해도 결과가 같아서 재시도로는 해결되지 않기 때문이다 (위 "재시도하지 않는 경우"와 같은 원칙). 실패한 검사 항목과 값을 출력하고 중단한다.
