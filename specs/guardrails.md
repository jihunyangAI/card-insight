# guardrails.md — 절대규칙과 검증 방법

## 1. 로컬 전용
- 분석·리포트 생성 전 과정에서 네트워크 호출을 하지 않는다. main.py는 외부 API·LLM을 호출하지 않는다.
- 이유: 카드 이용내역은 생활 패턴이 드러나는 민감 정보다.

## 2. PII 마스킹 (merchant_normalizer.mask_text / mask_holder)
| 대상 | 탐지 | 치환 |
|---|---|---|
| 카드번호 | 숫자 4-4-4-4(일부 `*` 포함, 구분자 `-`/공백 허용) | `****-****-****-****` |
| 전화번호 | `0`으로 시작하는 2~3 / 3~4 / 4자리 | `***-****-****` |
| 이름 | `성명·이름·회원명·예금주·명의` 라벨 뒤 한글 2~4자, 그리고 카드구분/이용자 컬럼 값 중 `본인·가족·-`이 아닌 값 | `***` |
- 거래를 읽는 즉시(loader) 가맹점명·이용자 값에 적용한다. 리포트와 메모리에는 마스킹된 값만 들어간다.

## 3. 외부 전송 금지 (merchant_normalizer.Anonymizer)
- 앞으로 LLM 호출을 추가하더라도 가맹점명·금액·날짜는 `[M001]`·`[A001]`·`[D001]` 토큰으로 바꾼 뒤에만 보낸다.
- 전송 직전에 `Anonymizer.assert_clean(payload)`로 원문 값이 남아 있지 않은지 검사하고, 남아 있으면 `PrivacyViolation`으로 중단한다.
- 토큰 → 원문 복원(`restore`)은 로컬에서만 한다.
- main.py의 표준출력은 Claude Code(외부 API)가 읽으므로 외부 전송으로 본다. 금액•가맹점명•거래 날짜를 출력하지 않고 비율과 카테고리명만 출력한다 (architecture.md "표준출력 규칙").

## 4. 단정 금지 (advisor.assert_non_assertive)
- 제안 문장 형식: `{카테고리} 카테고리 지출이 전월 대비 {X}% 증가(...). {점검 포인트} 검토 권장.`
- 금지 표현: `끊어`, `끊으세요`, `안돼`, `안 돼`, `사지마`, `사지 마`, `하지 마`, `그만`, `절대`, `반드시 줄`, `당장`. 리포트에 쓰기 전에 검사하고, 발견되면 리포트를 만들지 않는다.
- 절감액은 항상 `(추정)`을 붙인다.

## 5. 면책문구
리포트 마지막과 답변 끝에 아래 문장을 **그대로** 표시한다. 코드에서는 `report_writer.DISCLAIMER` 한 곳에만 정의한다.

> ※ 본 리포트는 입력된 카드 이용내역만으로 로컬에서 자동 생성한 참고 자료이며, 금융·세무·투자 자문이 아닙니다. 카테고리 분류와 절감액은 추정치로 실제와 다를 수 있으니, 지출 결정은 본인의 상황에 맞게 직접 판단하시기 바랍니다.

## 6. 운영 한도
- 시간: 요청당 60초. 단계마다 남은 시간을 확인하고, 넘으면 종료코드 4로 중단한다.
- 토큰: 요청당 40,000. 현재 main.py는 LLM을 호출하지 않으므로 소비량은 0이다. LLM을 추가하면 호출 전에 예산을 확인한다.

### 카드분석 가드레일
위 1~6번 항목과 겹치는 부분은 위 항목을 따른다.

- 절대거부 : 카드번호•이름•전화번호를 마스킹하지 않은 채 외부로 호출하는 것 (2번)
- 절대거부 : 가맹점명•금액•날짜를 외부 API에 그대로 보내는 것 (3번)
  - 카테고리 분류는 로컬 키워드 규칙으로만 한다 (retry_policy.md "카드분석검증"). 외부 LLM으로 분류하지 않는다.
  - 나중에 외부 호출을 추가하는 경우에만 익명화 토큰으로 치환한 뒤 호출한다.
- 절대거부 : "OO끊어"•"OO사지마" 같은 단정 표현 (4번)
  - 발견되면 다른 말로 바꿔 내보내지 않고, 리포트를 만들지 않고 중단한다.
  - 제안 문장은 처음부터 "검토 권장"•"우선 줄여볼 만함" 형식으로 만든다.
- 절대거부 : 특정 신용대출•카드•금융상품 추천 (자본시장법•투자자문업 해당 소지 회피)
- 단일 가맹점 월 100만원 이상 지출을 강조할 때는 전월에도 같은 패턴이었는지 확인한 뒤 표시한다.
  - 확인은 입력 데이터에 있는 전월 거래로 자동으로 한다. main.py는 실행 중 사용자에게 묻지 않는다.
  - 전월에도 100만원 이상이었으면 "전월에도 동일 패턴", 아니면 "전월 대비 신규 패턴"으로 표시한다. 전월 데이터가 없으면 "전월 데이터 없음"으로 표시한다.
  - 메모리 월별 요약에는 가맹점별 금액이 없으므로(memory_policy.md), 전월이 입력 데이터에 없으면 "전월 데이터 없음"으로 처리한다.

### 거부 메시지 형식
- PII 외부전송 또는 단정 표현: "이 요청은 PII외부전송 또는 단정표현을 포함합니다. 에이전트는 익명화된 분석과 제안만 제공합니다."
- 금융상품 추천: "이 요청은 특정 금융상품 추천을 포함합니다. 에이전트는 지출 분석과 절약 제안만 제공하며, 금융상품 추천은 하지 않습니다."
